# دفتر — تطبيق الحصص والواجبات

تطبيق ويب تقدمي عربي (PWA) يعمل محليًا دون حساب أو قاعدة بيانات خارجية. الواجهة RTL، والتصميم فحمي ونحاسي، والبيانات محفوظة في `localStorage` على الجهاز.

## الملفات

- `index.html` — بنية التطبيق.
- `style.css` — التصميم المتجاوب.
- `app.js` — الجدول والواجبات والبحث والأرشيف والإعدادات والحفظ والترحيل.
- `manifest.webmanifest` — إعدادات التثبيت.
- `sw.js` — التخزين المؤقت والعمل دون اتصال.
- `icons/icon-192.png` و`icons/icon-512.png` — أيقونتا PWA.

## التشغيل والتثبيت

1. ارفع محتويات المجلد كما هي إلى استضافة static تدعم HTTPS (مثل GitHub Pages أو أي استضافة ملفات ثابتة).
2. افتح رابط الموقع في Chrome على Android.
3. من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار.
4. افتح «دفتر» من الأيقونة. بعد أول تحميل ناجح، تُخزّن ملفات التطبيق الأساسية ويمكن فتحه دون اتصال.

يمكن تشغيله محليًا للاختبار من مجلد المشروع باستخدام خادم محلي، مثل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`. فتح `index.html` مباشرة عبر `file://` لا يفعّل PWA أو Service Worker؛ يلزم HTTPS أو localhost.

## الحفظ والترحيل

- المفتاح الحالي: `daftar_app_v2`.
- عند عدم وجوده، يفحص التطبيق المفتاح القديم `daftarAlhisas_v1` ويحاول تحويل الجدول والواجبات.
- لا يحذف التطبيق المفتاح القديم بعد الترحيل؛ يظل نسخة رجوع.
- إذا فشل الترحيل أو تعذرت قراءة البيانات، يمنع التطبيق الكتابة فوق المصدر القديم ويعرض تنبيهًا.
- لا يحذف الواجبات عند تغيير الأسبوع. تاريخ كل واجب محفوظ معه.
- النسخة الاحتياطية تُنزّل كملف JSON من الإعدادات.

## تحديث التطبيق

عند إصدار نسخة جديدة، حدّث قيمة `CACHE_VERSION` في `sw.js`، ثم ارفع الملفات الجديدة. سيُنشئ Service Worker ذاكرة تخزين جديدة ويحذف ذاكرة التطبيق القديمة فقط؛ بيانات المستخدم في `localStorage` لا تدخل ضمن ذاكرة التخزين المؤقت ولا تُحذف عند التحديث.

## ملاحظة الأيقونة والصورة المرجعية

لم تكن صورة مرجعية أو ملف الأيقونة المعتمد السابق متاحين ضمن الملفات المرفقة بهذه المحادثة. لذلك يحتوي هذا الإصدار على أيقونة دفتر نحاسية مؤقتة مرسومة لتناسب الاسم والألوان المطلوبة. يمكن استبدال ملفي PNG بالأيقونة الأصلية لاحقًا مع الإبقاء على الاسمين والمقاسين.
